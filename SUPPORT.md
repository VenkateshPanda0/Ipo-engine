# Getting help

IPO Engine is maintained by one person, so this page says where a question goes and what to expect.

| You have | Go to |
|---|---|
| A question about using it | Read the README ("How to use it") and `docs/README.md` first; then open an issue with the **Bug report** form if something does not work as described |
| A figure the software got wrong | The **Wrong figure** issue form. These are the most useful reports there are |
| An idea | The **Feature request** form; check `docs/roadmap.md` first |
| A security problem | **Do not open an issue.** Use a private security advisory (Security tab, "Report a vulnerability"); see `SECURITY.md` |
| A conduct concern | `CODE_OF_CONDUCT.md` |

What to expect: this is not a commercial service and there is no support contract or response-time
guarantee. Security reports are acknowledged within 5 days (`SECURITY.md`); everything else is answered
when time allows. Use public filings only in anything you post, and never paste API keys or
confidential documents.

Contact for anything that does not belong in an issue (a conduct concern, a rights request, a security
report that cannot use GitHub's private reporting): **venkateshpanda00@gmail.com**.

Not investment or legal advice. Check every figure against the page it cites.
